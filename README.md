# Spēles koncepcijas dokumentācija
**Nosaukums:** Nāve & riebums katakumbās
  
**Mērķauditorija:** 16–35 g.  
**Mehānika:** Spēle izmanto standartus RPG elementus, spēlētājs izvēlas varoņa statistikas un lomu. Paša spēlē notiek kustoties caur procedurāli-ģenerētu karti. Katrā kartes istabā notiek randomā-izvēlēts notikums, piem. monstru uzbrukums, tirgotājs, slazds vai bedre, kurai vajag pārlekt. Interakciju ar šiem elementiem ietekmētu statistikas, piem. inteliģence lai pamanītu slazdus, atlētika lai pārlektu bedrei, vai harizma lai veiktu tirzniecību ar tirgotāju.  

**Persona:** N. Jevdokimovs (15 g.) - patīk D&D un dažādas stratēģiskas datorspēles (piem. Slay the Spire un dažādas tradicionālās Roguelike spēles.)
